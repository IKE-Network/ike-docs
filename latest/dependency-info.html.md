# Maven Coordinates

```

  <groupId>network.ike.docs</groupId>
  <artifactId>ike-docs</artifactId>
  <version>38</version>
  <type>pom</type>
</dependency>
```

## [Apache Ivy](#apache-ivy)

```
<dependency org="network.ike.docs" name="ike-docs" rev="38">

</dependency>
```

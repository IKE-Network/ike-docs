# Maven Coordinates

## [Apache Maven](#apache-maven)

```
<dependency>
  <groupId>network.ike.docs</groupId>
  <artifactId>docbook-xsl</artifactId>
  <version>45-SNAPSHOT</version>
</dependency>
```

## [Apache Ivy](#apache-ivy)

```
<dependency org="network.ike.docs" name="docbook-xsl" rev="45-SNAPSHOT">
  <artifact name="docbook-xsl" type="jar" />
</dependency>
```

## [Groovy Grape](#groovy-grape)

```
@Grapes(
@Grab(group='network.ike.docs', module='docbook-xsl', version='45-SNAPSHOT')
)
```

## [Gradle/Grails](#gradle-grails)

```
implementation 'network.ike.docs:docbook-xsl:45-SNAPSHOT'
```

## [Scala SBT](#scala-sbt)

```
libraryDependencies += "network.ike.docs" % "docbook-xsl" % "45-SNAPSHOT"
```

## [Leiningen](#leiningen)

```
[network.ike.docs/docbook-xsl "45-SNAPSHOT"]
```

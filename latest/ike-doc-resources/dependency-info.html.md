# Maven Coordinates

## [Apache Maven](#apache-maven)

```
<dependency>
  <groupId>network.ike.docs</groupId>
  <artifactId>ike-doc-resources</artifactId>
  <version>71</version>
</dependency>
```

## [Apache Ivy](#apache-ivy)

```
<dependency org="network.ike.docs" name="ike-doc-resources" rev="71">
  <artifact name="ike-doc-resources" type="jar" />
</dependency>
```

## [Groovy Grape](#groovy-grape)

```
@Grapes(
@Grab(group='network.ike.docs', module='ike-doc-resources', version='71')

```
implementation 'network.ike.docs:ike-doc-resources:71'

```
libraryDependencies += "network.ike.docs" % "ike-doc-resources" % "71"
```

## [Leiningen](#leiningen)

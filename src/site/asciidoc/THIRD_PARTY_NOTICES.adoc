= IKE Docs — Third-Party Notices
:icons: font
:source-highlighter: coderay
:toc: preamble
:toclevels: 3

This document acknowledges third-party open-source software that
`ike-docs` depends on, links against, ships within classified
artifacts, or invokes at document-render time. The Maven
`licenses.html` and `dependencies.html` reports cover declared
`<dependencies>` mechanically; this document covers the rest — the
AsciiDoc rendering chain, embedded fonts, DocBook XSL toolchain,
diagram rendering, and frontend assets bundled into the rendered
HTML.

For corresponding notices in the rest of the IKE platform see:

* `link:../ike-tooling/THIRD_PARTY_NOTICES.html[ike-tooling]` — Maven
  build infrastructure, plugin core, signing.
* `link:../ike-platform/THIRD_PARTY_NOTICES.html[ike-platform]` —
  Java toolchain, BOM-managed dependencies, test framework.

== AsciiDoc rendering toolchain

|===
| Component | License | Role

| https://asciidoctor.org/[AsciidoctorJ]
| MIT
| The Java entry-point for the Asciidoctor renderer. `ike-doc-maven-plugin`
  invokes it via the official Maven plugin to convert `.adoc` source
  to HTML, DocBook, and XHTML.

| https://github.com/asciidoctor/asciidoctorj-pdf[AsciidoctorJ PDF]
| MIT
| Direct PDF rendering of AsciiDoc. The `prawn` profile in
  `ike-parent` activates this renderer; output is post-processed for
  page-break and font handling.

| https://github.com/asciidoctor/asciidoctorj-diagram[AsciidoctorJ Diagram]
| MIT
| Inline diagram rendering. Used together with the Kroki extension
  to support PlantUML, Graphviz, Mermaid, and similar formats inside
  AsciiDoc source.

| https://github.com/asciidoctor/asciidoctor-maven-plugin[Asciidoctor Maven Plugin]
| MIT
| The Maven plugin wrapper that drives AsciidoctorJ from the build.

| https://github.com/asciidoctor/asciidoctor-doxia[Asciidoctor Parser Doxia Module]
| MIT
| Lets `maven-site-plugin` natively render `src/site/asciidoc/*.adoc`
  alongside the auto-generated reports. (Replaced an earlier
  pre-render step in #310.)

| https://www.jruby.org/[JRuby]
| EPL 2.0 / GPL 2.0 / LGPL 2.1 (multi-licensed at consumer's choice)
| The embedded Ruby runtime that Asciidoctor itself runs on. Pulled
  in transitively by AsciidoctorJ.

| https://github.com/koncept-asciidoc/koncept-asciidoc-extension[Koncept AsciiDoc Extension]
| MIT
| In-house extension (vendored in this reactor as
  `koncept-asciidoc-extension`) that adds Koncept macros to
  AsciiDoc source.
|===

== Diagram rendering

|===
| Component | License | Role

| https://kroki.io/[Kroki] (PlantUML, Graphviz, Mermaid, BlockDiag, etc. backends)
| MIT (Kroki orchestrator)
| External HTTP service that renders diagram blocks. The IKE Network
  runs a private Kroki instance at `kroki.komet.sh`; documents that
  contain diagram blocks call it at render time. Each backend has
  its own license — PlantUML (GPL 3.0), Graphviz (CPL 1.0), Mermaid
  (MIT), etc. Diagrams render server-side; the rendered SVG/PNG is
  embedded in the output.
|===

== External PDF renderers (runtime, not bundled)

Several PDF renderer profiles in `ike-parent` shell out to external
binaries the user installs locally. The IKE build does not bundle
or redistribute these binaries; consumers install them directly.

|===
| Component | License | Role

| https://www.princexml.com/[Prince XML]
| Commercial; free for personal/non-commercial use
| High-quality CSS-Paged-Media renderer used by the `pdf-prince`
  profile.

| https://www.antennahouse.com/[Antenna House Formatter]
| Commercial
| XSL-FO renderer used by the `pdf-ah` profile.

| https://weasyprint.org/[WeasyPrint]
| BSD-3-Clause
| CSS-Paged-Media renderer (Python) used by the `pdf-weasy` profile.

| https://xmlgraphics.apache.org/fop/[Apache FOP]
| Apache 2.0
| XSL-FO renderer used by the `pdf-fop` profile.

| http://www.renderx.com/[RenderX XEP]
| Commercial; free personal license available
| XSL-FO renderer used by the `pdf-xep` profile.

| https://github.com/asciidoctor/asciidoctorj-pdf[AsciidoctorJ PDF (Prawn)]
| MIT
| The default profile (`pdf` / `prawn`); listed above.
  Included here for completeness — this one IS bundled and runs
  in-process.
|===

== Verification

* `mvn site` populates `target/site/licenses.html` from declared
  `<dependencies>`. AsciidoctorJ family, JRuby, and the test
  frameworks appear there.
* `mvn site` populates `target/site/plugins.html` and
  `target/site/plugin-management.html` from declared
  `<build><plugins>` and `<build><pluginManagement>`.
* This curated document complements those mechanical reports for
  the runtime renderers, fonts, frontend assets, and external
  services that aren't visible to `licenses.html`.
